# Weather App

A simple weather application built with HTML, CSS, and JavaScript.  
It fetches real-time weather data using the OpenWeather API and displays temperature, humidity, wind speed, and weather conditions with dynamic icons.

## Features

- Search weather by city name
- Real-time weather data using API
- Dynamic weather icons (Clear, Clouds, Rain, etc.)
- Displays:
  - Temperature
  - Humidity
  - Wind speed
- Saves last searched city using localStorage
- Automatically loads last searched weather on refresh

## Built With

- HTML5
- CSS3
- JavaScript (ES6+)
- OpenWeather API
